## ⚡ Installation

To get started with `dv-nvim-config-perso`, follow these simple steps:

1.  **Backup your existing Neovim configuration (optional but recommended):**
    ```bash
    mv ~/.config/nvim ~/.config/nvim_backup
    mv ~/.local/share/nvim ~/.local/share/nvim_backup
    mv ~/.cache/nvim ~/.cache/nvim_backup
    ```
2.  **Clone this repository:**
    ```bash
    git clone https://github.com/dvrch/dv-nvim-config-perso.git ~/.config/nvim
    ```
3.  **Launch Neovim:**
    ```bash
    nvim
    ```
    Neovim will automatically install the necessary plugins.
